# Security policy

## Supported versions

The latest release on `main` receives security fixes. Older versions are not patched; upgrade to the latest release.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's [private vulnerability reporting](https://github.com/milanhorvatovic/reducible/security/advisories/new) for this repository, or by email to <milan.horvatovic@gmail.com>. Include the affected module and version, a description of the issue, and steps or code to reproduce it.

You will get an acknowledgement within a week. Once the report is confirmed, a fix is prepared on a private branch, released, and the advisory published with credit to the reporter unless they prefer otherwise.
