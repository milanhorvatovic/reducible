# Cookbook iOS app

SwiftUI host for the Cookbook example. It consumes the `Shared` framework built by `examples/cookbook/shared`, which exports the library's runtime, the four feature modules, and the SwiftUI bridge from [`swift/`](../../../swift).

Open `iosApp.xcodeproj` in Xcode and run. A pre-build script phase assembles the framework through the root Gradle wrapper (`:examples:cookbook:shared:embedAndSignAppleFrameworkForXcode`), falling back to the Android Studio JBR when `JAVA_HOME` is unset.

The project file is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` — edit the yml and regenerate (`xcodegen generate`) instead of editing target settings in Xcode; the committed `iosApp.xcodeproj` exists so that opening the project requires no tooling.
